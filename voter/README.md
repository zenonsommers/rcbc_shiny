# voter
<!-- badges: start -->
<!-- badges: end -->

**voter** is the election engine for the RCBC Shiny Election Suite.

## Goal

Provide a clean, versioned, and tested R package interface to the election algorithms (CPO-STV, Borda, STV) used by the Shiny app.

## Installation

```R
devtools::install("/path/to/rcbc_shiny/voter")
```
